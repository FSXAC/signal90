# SIGNAL/90

A cassette-futurism UI design system: emissive type on a dead-black CRT, flat screens, stretched Helvetica, boxed labels, engineered ornament and alarms that strobe on the anime frame.

- **Demo reel:** `demo-reel.html` has 41 screens, including 13 "never evolved" takes on modern UIs (analytics, status page, market, fitness, weather, music, navigation, chat, CI/CD, git graph, system monitor, 2FA, calendar), plus the system docs.
- **Kit:** `signal90/signal90.css`, `signal90/signal90.js`, starter `signal90/template.html`.
- **Machine-readable guide:** `signal90/guide.json` (rules, components, motion, layout, JS API, checklist) and `signal90/tokens.json` (DTCG tokens). Coding agents start at `AGENTS.md`.

No build step. Open the HTML files or serve the folder statically.

All scene copy, names and emblems are original. The reference frames studied while building the system are not included in this repository.
